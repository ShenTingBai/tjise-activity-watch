## 1. 为什么是「说明 + 更多」

顶栏原先只有一个「说明」，后来把重看引导、版本、数据目录都塞进「设置」。两轮下来暴露出两个问题：
学习入口（想学怎么用）和查找入口（想找版本/目录）挤在一个弹窗里，新用户既找不到操作主线，
老用户也找不到版本位。三个方案：

| 方案 | 结论 | 理由 |
|---|---|---|
| 只留「更多」，说明也埋进第二层 | 不采用 | 新用户第一次要知道「怎么用」，藏进二级会让开始成本更高 |
| 扩成完整设置页 / 侧栏 / 标签页 | 不采用 | 当前只有三项动作，扩页会造出空分区与多余导航，也超出这次返修范围 |
| **说明 + 更多**（采用） | 采用 | 学习入口直接可见；非配置类辅助动作收在「更多」，两者职责清楚 |

职责切分：

| 入口 | 回答 | 内容 |
|---|---|---|
| 顶栏「说明」 | 我该怎么操作 | 三步快速帮助 + 「重看引导」快捷入口 |
| 顶栏「更多」 | 版本是多少、数据在哪、想再看一遍引导 | 一块浅琥珀引导区 + 版本行 + 本机数据行 |
| 六步引导 | 每个分区在哪、干什么 | 六个稳定高亮目标，可跳过、可暂停、可重播 |

三者是**并列的三个入口**，不是「更多」套「说明」的层级；说明**不是**「更多」的替代品。

## 2. 桌面线框（600px）

```
┌ 更多                                          × ┐
│ ┃ 操作引导                     [重看引导 · 琥珀] │
│ ┃ 分区高亮，跟着走完六步。                       │
│   当前版本  1.1.0                 [查看发布页]   │
│   用浏览器查看和下载新版。                       │
│   ──────────────────────────────────────────    │
│   本机数据                     [打开数据目录]    │
│   登录态、偏好和运行记录保存在本机数据目录。     │
│   Esc 关闭                            [关闭]     │
└─────────────────────────────────────────────────┘
```

- 只有**一块**强调区（引导区）；版本与数据是普通行 + 细分隔，不做三张同形卡片叠套。
- 头尾固定，只有正文滚动；矮窗口下头尾不会滚出屏。

## 4. 真实文案（与实现同字）

| 位置 | 文案 |
|---|---|
| 顶栏按钮 | `更多`（`aria-label="更多：重看引导、版本与本机数据"`） |
| 弹窗标题 | `更多` |
| 关闭按钮 | `×`，`aria-label="关闭更多"` |
| 引导区标题 | `操作引导` |
| 引导区说明 | `分区高亮，跟着走完六步。` |
| 引导区按钮 | `重看引导` |
| 版本行 | `当前版本` + `bootstrap.version` + `用浏览器查看和下载新版。` + `查看发布页` |
| 数据行 | `本机数据` + `登录态、偏好和运行记录保存在本机数据目录。` + `打开数据目录` |
| 页脚 | `Esc 关闭` / `关闭` |
| 忙态按钮 | `计划结束后可重看引导`（禁用） |

三步快速帮助（说明弹窗与 `Api.help()` 同字）：

1. **确认登录** —— 首次点「登录」，在浏览器里完成登录。重开会自动检查；仅在提示失效时重新登录，暂时无法确认就刷新。
2. **选活动并开始** —— 勾选不冲突的活动，设置重试时长和最多次数，再点「开始报名计划」。未来场次等开放，已开放场次立即尝试。
3. **看进度与结果** —— 电脑保持唤醒和联网，窗口可最小化。逐场看结果；停止会结束本机任务，不会撤销学校报名。

边界提醒：`仅操作本人账号；选中活动还没有开始，报名结果以学校活动页为准。`

## 6. 状态矩阵

| 状态 | 表现 |
|---|---|
| 未登录 / 组件报错 / 列表失败 | **更多**仍可打开；版本与目录可查；重播可用（不依赖登录） |
| 计划运行中 | 更多可打开；两处重播都禁用，按钮文字变 `计划结束后可重看引导`；点击不打断计划 |
| 说明已打开 | 再点「更多」→ 说明让位，两个模态不叠开 |
| 发布页打不开 | 只在弹窗内给局部反馈，并把固定地址摆成可选文本；不在 WebView 内导航 |
| 数据目录打不开 | 只在弹窗内给局部反馈 + 下一步；不弹结果框、不刷运行记录 |
| 键盘 | `Tab` 在弹窗控件间原生移动；`Esc` 关闭；弹窗打开时 `Enter`/`Esc` 不穿透到背景 |
| 引导退出 | 焦点回到触发重播的顶栏入口（`#btn-settings` 或 `#btn-help`） |
| 动效 | 无入场轮播/卡片飞入；尊重 `prefers-reduced-motion` |

## 7. 这次**没有**改的东西

- 主界面视觉：候车厅、白色时刻表、黑底琥珀 LED、路线图、尺寸断点都不动。
- 软件版本：仍是 `1.1.0` 候选；本轮 UI 返修不升版。
- 引导：六步顺序、`data-tour-target` 锚点、跳过/完成/忙时暂停/窄窗降级机制不变；
  只有第 2/5/6 步文案修正，故 `TOUR_VERSION` 由 1 升到 2（内容版本，与软件版本无关）。
- 业务：不改 worker 调度、报名模式、冲突、重试策略、签到/签退三态与停止链路。

## 生成方式与口径

- **来源**：生产 `local/ui/`（index.html / styles.css / app.js / led.js）字节级副本，
  仅在副本里注入一段 `mock-bridge.js` 提供 pywebview API 假实现；**源文件未改动**。
- **数据**：全部为 mock 演示数据（七场活动：未来预报名 / 同批非冲突 / 冲突 / 已开放 / 签到未知 /
  待公布 / 已报名各形态），无任何真实姓名、学号、凭证，未访问学校站点——渲染时网络层只放行
  `file://`，其余请求一律阻断（运行记录为「无外部请求」）。
- **工具**：Playwright（`channel="msedge"` 无头）+ 本地 route guard；视口 1120×800 @100%
  （与 `local/app.py` 窗口尺寸一致）。
- **引导截图**：用界面自身的 `startTour(n)` 手动重播（等价于说明页「重新看一遍引导」），
  不是首次自动弹出的那条路径；主图先勾选一场（与用户点复选框同一代码路径）再截。
- **版本与环境**：生成时 VERSION 草案号为 `3.1.0`；分支 `codex/lifecycle-tour-release` @ `3f33b85`，
  截图时界面实现与引导/生命周期代码**尚未提交**（与截图同批待用户验收）。
- **版本线更正（2026-10-25 返修）**：软件候选已从内部草案 3.1.0 收敛为 **1.1.0**（见
  [specs/versioning-and-release](../specs/versioning-and-release.md)）。本目录 PNG **未重新截取**，
  仍如实反映 3.1.0 草案期生成事实——图内不含可见版本号，视觉与 1.1.0 候选一致；
  这些图是 mock 源码渲染，不代表任何 EXE 构建或 1.1.0 发布产物。

## 边界（不要当验收结论）

- 这是**源码渲染预览**，不等于 EXE 构建产物，也不等于有效登录下的真机验收。
- 「登录有效 约剩 8 小时」「已复用本机登录态」等状态为 mock 注入，不代表学校接口结论。
- 首次打开的自动引导、关闭时长提示等生命周期行为在真机上的表现，见

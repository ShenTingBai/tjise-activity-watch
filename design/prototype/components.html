点阵屏

5×7 点阵，点半径是点距的 0.36。灭着的点也画出来（暗色），所以数字变化时不跳版，看上去像一块真屏。只画倒计时用得到的字，外加 ✓ / ✕ 两个结果图标。

大屏状态

大屏是界面里唯一的「任务位」，对应 app.py 同一时间只跑一个子进程的锁。谁占着位置就显示谁；任务结束后结论留在屏上，点「知道了」或选别的行才收起。完整状态机见设计文档 §5。

顶栏

登录胶囊回答「登录还能用多久」。剩余时间按登录时刻加 17.5 小时估算（app.py 的算法），所以写「约剩」。点胶囊看预计到期时刻和重新登录入口。

登录胶囊：有效 / 快过期（不到 2 小时）/ 失效 / 还没登录 / 正在登录 / 连不上
本机时钟：和学校差 3 秒以上才标出来（grab.py 的门槛）

按钮

屏上的主按钮用琥珀实底，一块屏上最多一个；它的文字永远说清会发生什么：「到点自动报名」「立即替我报名」「先重新登录」「再试一次」。

屏上：主要 / 悬停 / 不可用 · 次要 · 文字链
厅里：实心（需要马上做的那一步，例如还没登录时的「登录」）/ 描边 / 透明 / 刷新中

时刻表行

左边是开放时刻（大号 Bahnschrift，学校爱用的 :59 秒写成上标），右边一格回答「还要等多久 / 现在能不能报」。每秒只改右边那格文字；开放、截止这种跨界才整表重画。

横幅与提示

横幅只给两种会让这次报名白等的情况：断网、电脑睡过一觉。其余的反馈都在大屏上，不弹窗打断。轻提示只确认一个刚做完的动作。

动效

只有一个刻意安排的动效：点「到点自动报名」那一下，点阵屏闪着亮起来，像车站换牌。其余都是对状态的提示。系统开了「减少动态效果」时全部关掉。

动效什么时候时长说明
点阵屏闪亮点「到点自动报名」「立即替我报名」420ms只这一次；之后每秒跳字不带动画
呼吸点「等开放」「正在登录」「提交中」标签上的小圆点1.4s 循环告诉人程序没卡死；最后几秒的站点 1s 循环
大屏换状态大屏内容整体换掉时160ms 淡入每秒的数字更新不触发
弹窗、轻提示打开时140–180ms上移 6px + 淡入
刷新中拉列表时0.9s 循环刷新图标转圈；列表顶上一条 2px 扫光

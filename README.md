# 校园活动「到点自动报名」—— 本机版

> 这个文件同时是 GitHub **`local` 分支**的首页。三条分支的分工：
> `main` 源码总仓（两版并存）、`local` 本机版快照（就这一份，根目录双击即用）、`server` 服务器版快照。
>
> 不想装 Python：到 [Releases](https://github.com/ShenTingBai/tjise-activity-watch/releases) 下载
> **当前 Release 实际提供**的资产——**完整 ZIP** `tjise-activity-watch-vX.Y.Z-win-x64.zip`
> （约 60 MB，解压双击主 EXE 就能用，内置依赖，使用电脑上的 Chrome 或 Edge）
> 或 **独立 EXE** `tjise-activity-watch-vX.Y.Z-win-x64.exe`（单文件，拷到空目录双击即用）。
> 两种形态的程序是同一份 EXE，数据位置相同。
> **安装版 `tjise-activity-watch-installer-vX.Y.Z-win-x64.exe` 是未发布候选**：脚本与清单已就绪，
> 会随下一个正式版本并列发布；现在发布页上还没有，想试用只能在干净工作区自己构建。
> `tjise-grab-portable-*.zip` 绿色版是 **v1.0.2 及以前的历史形态**，已停止新增发布，新用户别下。

只用自己电脑，不需要服务器。服务器版（定时推送、飞书机器人、无人值守重登）在仓库的 `server/` 目录，也可以直接看分支 [`server`](https://github.com/ShenTingBai/tjise-activity-watch/tree/server)。

一个**不需要服务器**的小工具：在你自己的 Windows 电脑上登录一次，之后把多场活动加入计划，脚本会在各自开放时刻自动点「立即报名 → 确定」。

适用于「天软智慧校园」活动中心的第二课堂活动（站点 `https://xg.tjise.edu.cn/stu/`），**只对天津市大学软件学院（天软）专升本学生有效**。

## 一、先说清楚边界

这个工具只在你自己的账号上运行报名计划：每场活动在报名开放的那一刻提交，计划统一协调不同开放批次。

- ✅ 只操作你本人的账号（登录状态来自你自己手动登录）
- ✅ 只点「立即报名」和弹窗里的「确定」，不碰别的接口
- ✅ 密码不落盘：登录在真实浏览器窗口里由你手动输入（含图形验证码），程序只保存 cookie/localStorage
- ❌ 不代他人报名、不批量提交、不做任何绕过风控的操作
- ❌ 报上名就等于占用名额，不想去请尽快在活动页取消，别浪费

请遵守学校关于活动的管理规定；本工具只是把「到点手动点报名」这件事自动化，
能不能报上、名额多少，始终由学校系统决定。

## 二、准备（只做一次）

需要 **Windows 10/11** + **Python 3.10 或更高**。

**双击 `install.bat`** 就行，它会自动做完四件事：

| 步骤 | 动作 |
|---|---|
| 1 | 检查 Python 版本（没装会提示去哪下、要勾哪个选项） |
| 2 | 装依赖 `playwright` + `pillow` + `pywebview`（默认源失败自动换清华镜像） |
| 3 | 下载浏览器内核（失败换国内镜像；再失败就用你电脑上的 Chrome） |
| 4 | 自检：能不能拉起浏览器、能不能连上学校站点 |

看到 `[OK] 打开成功` 和「安装完成」就可以往下走了。

> 没有 Python？先装：<https://www.python.org/downloads/>，安装第一屏**务必勾选 "Add python.exe to PATH"**，装完重新双击 `install.bat`。

### 完全不想装 Python：用绿色版

拿到 **`tjise-grab-portable.zip`**（约 59 MB，解压后 150 MB）的话，**不用装 Python、不用跑 install.bat**：

1. 解压到任意目录（路径别带中文和空格，例如 `D:\tjise-grab`）
2. 双击 **`启动.bat`** —— 界面就起来了

里面自带解释器和依赖，只借用你电脑上的浏览器（Chrome 或 Edge 都行，Win10/11 一定带 Edge）。
想用命令行的话，把 `python` 换成 `python\python.exe` 即可，例如 `python\python.exe grab.py list`。

> 绿色版是从 `make_portable.py` 构建出来的：`python make_portable.py`。想自己重新打一份就运行它。
> 打包用的是官方嵌入式 Python + 这台机器上装好的依赖，**不捆绑浏览器内核**，所以比 PyInstaller 小很多、也不容易被杀软误报。

### 分发形态（用户视角）

当前 Release 已发布两种，程序本体是同一份 EXE，登录数据都在
`%LOCALAPPDATA%\TianSoftActivityPreRegistration\data`；安装版是待发布候选：

| 形态 | 状态 | 适合 | 说明 |
| --- | --- | --- | --- |
| **完整 ZIP** | 已发布 | 免安装 | 解压双击主 EXE；删文件夹即"卸载"（登录数据仍在上面那个统一位置） |
| **独立 EXE** | 已发布 | 单文件 | 内置程序组件（grab-worker），拷到空目录双击即用 |
| **安装版** | **候选，未发布** | 长期用 | 开始菜单项、控制面板卸载入口、中文向导；免管理员装到 `%LOCALAPPDATA%\Programs\TjiseActivityWatch`；发布前只能自己构建试用 |

历史形态：**绿色版** `tjise-grab-portable-*.zip`（v1.0.2 及以前，**停止新增发布**）。
它的数据在程序旁边的 `data/`、靠 `启动.bat` 启动，只保留历史下载和构建脚本
（`make_portable.py`），新用户请用上面两种。已发布的两种形态都需要 Windows WebView2
与 Chrome/Edge 之一。

**「程序装在哪」和「数据放哪」是两件事**，装到 Program Files 也不会改变数据位置：从 Vista 起
`C://Program Files` 对普通权限进程**不可写**，非提权程序往里写会被 UAC 拦下或静默重定向到
`%LOCALAPPDATA%\VirtualStore\`。所以安装版默认走「仅为我安装」（免管理员，程序落在
`%LOCALAPPDATA%\Programs\TjiseActivityWatch`）——这和 Chrome、VS Code 的做法一致。

卸载只删程序，不动 `%LOCALAPPDATA%\TianSoftActivityPreRegistration`。想连登录数据一起清，
卸载向导会单独问一次，**默认停在「否」**（按钮焦点也在「否」上），要你自己点了「是」才删；
**静默卸载（`/VERYSILENT`、`/SUPPRESSMSGBOXES`）一律保留**——消息框被抑制时的返回值不是
你的选择，没人回答的时候不能替你删登录态。

### 自己构建（开发者）

- **一条命令出全套资产**：`python tools/release.py --prepare` —— 构建一次冻结 onefile EXE
  （grab-worker 已内置，独立可用），再由**同一份 EXE** 派生三资产：独立 EXE、四成员完整 ZIP
  （EXE + README + 启动说明 + LICENSE）、安装版（内部调用 `build_installer.py`），外加 manifest
  清单（版本、完整 commit、source_dirty、每个文件的 SHA-256）。旧版「主 EXE 必须与
  `grab-worker.exe` 同目录」是历史旧包口径，已被 2026-10-25 的独立 EXE 决定取代（见
  `design/decisions/010-standalone-exe-and-settings.md`）。构建脚本不读 `data/`、不把登录态
  打进包；`X.Y.Z` 读仓库根 `VERSION`。资产是本地预览，只有 `tools/release.py --publish` 才会上
  GitHub——它要求干净 main、逐项核验三资产与来源一致、人工确认，默认不打 tag 不上传。
- **单独构建 EXE**：开发机装 PyInstaller 后 `python build_exe.py --mode onefile`；
- **单独构建安装版**：`python build_installer.py`（或 `--source dist/tjise-grab-exe-onedir`），
  产物在 `dist/installer/`。本机没装 [Inno Setup](https://jrsoftware.org/isdl.php) 会直接报错
  并给出地址，不会假装成功。**Inno Setup 免费**——个人用、商用、打包闭源软件都不收费，
  官方只接受自愿捐款，源码在 <https://github.com/jrsoftware/issrc>；唯一要求是 **6.3 或更新**
  （脚本用了 `x64compatible` 架构标识，6.3 才引入；本机实测 6.7.3）。
- **绿色版（历史形态，可自行构建）**：`python make_portable.py`，产物在
  `dist/tjise-grab-portable/`。数据在包旁边 `data/`，仅按历史口径维护，不进正式 Release。

**「程序装在哪」和「数据放哪」是两件事**，装到 Program Files 也不会改变数据位置：从 Vista 起 `C:\Program Files` 对普通权限进程**不可写**，非提权程序往里写会被 UAC 拦下或静默重定向到 `%LOCALAPPDATA%\VirtualStore\`。所以安装版默认走「仅为我安装」（免管理员，程序落在 `%LOCALAPPDATA%\Programs\TjiseActivityWatch`），登录态一律写 `%LOCALAPPDATA%\TianSoftActivityPreRegistration\data`——这和 Chrome、VS Code 的做法一致，不是「乱放」。

### 每种形态到底打了哪些文件

安装版的清单写在 `build_installer.py` 的 `INSTALL_FILES` 里，一个文件一行，**不走整目录拷贝**——构建目录里躺着的开发用文件不会跟过去：

| 形态 | 用户拿到的文件 |
| --- | --- |
| 安装版 | `tjise-activity-watch.exe`、`README.md`（= `local/README.md`）、`遇到问题先看我.txt`、`LICENSE`；开始菜单另加「遇到问题先看我」直达 |
| 完整 ZIP（Release） | 上面同样四项的等价物：EXE、`README.md`、`启动说明.txt`、`LICENSE` |
| 绿色版（历史） | EXE + 4 个 `.bat` 启动器 + `启动不了点我.txt` + 依赖 |

刻意**不打**的两样：`CHANGELOG.md`（开发记录，32 KB，用户不看）、`gui-preview.png`（README 在 GitHub 上的配图，装到本地是打不开的死文件）。构建时会打印一行「源目录里这些文件不会打包：…」，免得以为打进去了。排障说明分两份：`启动不了点我.txt` 面向 .bat 绿色版，`遇到问题先看我.txt` 面向安装版/解压版（写清了两种形态怎么区分、装在哪、数据在哪、怎么卸载）。

**安装向导是中文的**：语言文件 `local/installer/ChineseSimplified.isl` 跟着仓库走（官方 Inno 发行包不带中文），构建时复制到 `.iss` 旁边再引用，所以换台机器 clone 下来也能编出中文向导，不依赖本机有没有语言包。文件是 UTF-8 **带 BOM** 的——Inno 靠 BOM 判断 Unicode，存成无 BOM 会静默变乱码（官方 issrc 里的原文件就是无 BOM 的，照抄必踩）。文件缺失时退成英文向导，不会导致编译失败。

三种方式都需要 Windows WebView2，以及 Chrome 或 Edge 之一。PyInstaller 不负责安装浏览器内核；首次构建前也不会自动安装 PyInstaller。

## 三、三步走

### 第 1 步：登录（每次登录态过期后重做）

双击 **`1-登录.bat`**（或运行 `python grab.py login`）。

会弹出一个 Chrome 窗口，停在学生登录页：

1. 输入学号/账号、密码、图形验证码，点「立即登录」；
2. 登录成功后脚本会自动保存登录态并关闭窗口；
3. 看到 `[OK] 登录成功` 即可。

登录态大概能撑 **17 小时左右**（实测样本，不是保证值）。过期后重新做这一步就行。

> 关闭工具再打开**不需要**重新登录：启动时会先显示「检查登录…」，真实校验通过就直接复用（界面显示「已登录」，运行记录写「已复用本机登录状态」）。只有学校接口明确返回失效（4001）才重登；网络异常显示「登录待确认」，恢复后点「刷新」再试，已有登录不会被清掉。

### 登录态存在哪、重开还要再登一次吗

- **双击 bat / python 运行**：登录态在 `local/data/`（session.json + storage_state.json），关掉重开、再次运行都直接复用，不用重复登录。
- **EXE 版**：登录态统一存在本机的 `%LOCALAPPDATA%\TianSoftActivityPreRegistration\data`。**同一台电脑上**关闭重开、替换 EXE、甚至重新构建 EXE，打开时都会先用已有登录态真实访问一次学校接口——校验通过就直接用（界面显示「已登录」），不会重复弹登录窗口；只有学校接口明确返回登录失效（4001）才需要重新登录。网络或学校接口没应答时显示「登录待确认」，点「刷新」再试即可，**不会**因此清掉已有登录或逼你重登。**安装版同理**：哪怕装进了 `C:\Program Files`，数据也写这里，不会、也不能写进安装目录。
- 这些文件里只有登录凭证（cookie / token），**没有账号密码**；「约剩 17 小时」只是提醒文案，真正的失效以学校接口返回为准。
- **关闭时长与登录估算**：重开工具时点顶栏时间入口打开「时间详情」，能看到「上次退出至本次启动」（`使用记录`里）和「登录预计剩余时间」——正常关闭给精确值，上次是崩溃/断电退出的只显示「约」，首次运行显示「未知」。登录估算只在**新登录成功且有可信北京时间**时建立锚点，之后按独立北京时间继续计算（关着的那段时间照算），复用/刷新不续期，**只是提醒**：估算到点但学校校验有效时仍显示「已登录」；没有可信锚点就显示「未知（以学校校验为准）」，不要求为显示数字而重新登录。这些记录写在 `ui.json`，不碰登录文件。
- 想看或备份这些文件：右上角「帮助 → 打开数据目录」（运行记录展开后也有同名按钮）直接打开所在目录，**点完会把完整路径写回「本机数据」那段说明里**，可以直接选中复制，不用再去猜。高级用法可用环境变量 `TJISE_DATA_DIR` 指定别的位置（对开发和 EXE 版都生效，指定后上面显示的也是真实路径）。旧版 EXE 旁边 `data/` 里的登录态会在冻结程序首次启动时**复制**到统一目录——只补缺失、不覆盖已有文件，**原文件保留在旧位置不删除**，所以迁移后新旧两处都有。卸载的可选删除**只针对默认的 `%LOCALAPPDATA%\TianSoftActivityPreRegistration` 数据目录**：`TJISE_DATA_DIR` 指定的自定义目录、旧 EXE 旁留下的迁移源副本都不在卸载删除范围内，要清干净需你逐个确认路径后自行删除。
- **看版本与更新**：「帮助」显示当前版本（与 Release 资产同一来源，当前候选 1.1.1，发布前以仓库根 VERSION 为准）。点「检查更新」才查询 GitHub 最新正式版：有新版、当前最新、当前为预览版本或暂无正式发布会分别说明；断网、超时、限流等失败只在更新区提示，可重试。结果附检查时间，重开帮助或刷新界面可恢复本次结果，不会自动再次查询。「前往下载页」用系统浏览器打开固定发布页（只是打开网页，不自动下载或安装）；打不开会显示地址供复制。
- **重看引导**：「帮助 → 重看引导」重新走一遍六步。计划运行中该按钮禁用并写「计划结束后可重看引导」；帮助、版本检查和数据目录仍可使用。

### 第 2 步：看有哪些活动

双击 **`3-检查登录和活动.bat`**，会打印：

```
  #  报名开始  状态  活动名
  1  2026-10-22 00:59:59  未开放（1 小时 22 分后）  网络安全·数字时代大长城
  2  2026-10-21 10:00:00  开放中  我与学生面对面（天软信息化发展之路）
```

记住你要报名的那个活动的**报名开始时间**（也可以直接用第 3 步的交互选择）。

### 第 3 步：到点自动报名

**推荐：双击 `2-抢活动.bat`**（交互式到点自动报名），按提示输入序号并确认，脚本会：

| 时刻 | 动作 |
|---|---|
| 报名开放前约 100 秒 | 打开浏览器加载活动详情页（浏览器冷启动要十几秒，留足余量） |
| 开放前 5 秒 | 开始每 0.3 秒检查页面有没有「立即报名」按钮 |
| 按钮没出现时 | 最多每 2 秒刷新一次页面（避免把学校接口刷爆） |
| 开放瞬间 | 点「立即报名」→ 弹窗点「确定」→ 读服务端返回 |
| 失败 | 每 1.5 秒重试一次，最多重试 120 秒（名额满/未开放都会记下原因） |
| 结束 | 打印成功/失败结论；配了飞书 webhook 的话同时发一张卡片 |

选中的场次**已经开放**时不会傻等原定时刻：脚本立即开始提交，命令行同时打出
「原定开放」（学校原定时间）和「本次执行」（实际起点）两个时间，重试窗口从本次执行起算。

**或者用命令行指定**（适合提前写好、放在后台跑）。两种都行：

```bat
:: 按 list 里的序号（推荐，不用手抄活动 id 和时间）
python grab.py grab --pick 1

:: 按活动名关键词（只匹配到一个才继续）
python grab.py grab --name 网络安全

:: 显式指定（老办法，id 和报名时间都自己填）
python grab.py grab --activity-id 2ae75dd103654543b1a8b97053adf4a6 ^
                    --at "2026-10-22 00:59:59" ^
                    --name "网络安全·数字时代大长城"
```

`--pick` / `--name` 与 `3-检查登录和活动.bat` 打印的序号是同一份顺序；用这两种方式时不再二次确认，直接进入等待开放并自动报名。序号对不上时脚本会告诉你当前有几个，匹配到多个重名活动时会列出来让你改用序号——不会瞎猜一个报名。

常用参数：

| 参数 | 作用 | 默认 |
|---|---|---|
| `--pick N` | 按 list 的序号直接选 | 不用（则交互选择） |
| `--name 关键词` | 按活动名挑选；配合 `--activity-id` 时只作通知名 | 空 |
| `--lead 100` | 提前多少秒打开页面 | 100 |
| `--window 120` | 开放后最多重试多少秒 | 120 |
| `--headed` | 显示浏览器窗口（默认后台静默） | 关 |
| `--dry-run` | 只检查页面和按钮，不提交 | 关 |

**注意：保持电脑不睡眠、不断网。** 笔记本合盖会睡，错过了不是脚本的问题。

### 不想敲命令行？双击 `4-图形界面.bat`

![界面预览](gui-preview.png)

窗口名是**「天软活动预报名工具」**，一个窗口搞定，打开就会自动检查登录、拉一次活动列表：

- **界面气质**：来自早期「准点」视觉原型的车站候车厅、黑底 LED 计划大屏、白色活动时刻表和底部运行记录——「准点」只是那套设计稿的历史称呼，不是本工具的名字；实际数据和业务由当前 `app.py` 事件驱动。窄窗口下品牌名会缩短为「天软预报名工具」，窗口标题不变。
- **看状态**：顶部显示登录状态（快过期变橙）、独立北京时间入口（未校准显示「待校准」，点开有详情与重新校准）、活动总数、可报名数量和下一个开放时间；断网或电脑睡眠过会有顶部横幅提醒。
- **看时刻表**：活动按「正在开放 → 现在 → 今天/明天/以后 → 待公布 → 刚截止 → 已报名」分组；「下一场」有黑底标签，每秒只走倒计时，不重排整表。
- **双模式**：未来开放的场次是「**预报名**」——提前加入计划，工具会在学校原定开放时刻前 **100 秒**自动启动这一场：先打开活动详情页预热，开放前 5 秒进入高频盯按钮，开放后才提交；报名已开放但还没截止的场次是「**立即报名**」——选中后马上执行，重试窗口从本次启动起算；报名已截止的场次只能查看，复选框、整行点击和开始按钮都会拒绝它。每行、任务卡和大屏摘要都标着各自模式，混合计划里两种模式可以共存、逐场显示、互不阻塞（一场在重试中，另一场照样按自己的时刻启动）。
- **筛活动**：支持关键词、全部/未报名/已报名、时间、排序，以及“签到：全部/需要/无需”“签退：全部/需要/无需”。接口没有提供要求字段时会显示“待说明”，只在全部筛选里保留——学校字段还没确认时，宁可疑着，不要误判成无需。
- **加入计划**：每行独立勾选，选完大屏给出检查条（登录撑不撑得到开放、时钟准不准、是否 24 小时后才开放）。活动举办时间重叠时保留已有选择并提示冲突；同一报名开放时刻但举办时间不重叠的活动可以一起提交，不同开放批次会提前排队等待。
- **重试策略**：开始计划前可设「重试」（2 分钟/10 分钟/30 分钟/1 小时/直到报名截止）和「最多次数」（0=不限），默认 2 分钟 + 不限——长报名窗口**不会**默认持续运行，只有明确选「直到报名截止」才会挂到截止。活动的**报名截止时间是硬上限**，任何设置都不会越过它；活动没公布截止时间时，「直到报名截止」自动回退 2 分钟，绝不无限跑。设置会记住，下次打开不用重选。图解见 [docs/RETRY_POLICY_GUIDE.md](docs/RETRY_POLICY_GUIDE.md)。
- **运行计划**：点「开始报名计划」后，任务行显示每场等待、提交中（第 N 次提交 + 最近原因 + 重试截止，只有真正点「立即报名」发起的提交才计数，刷新和查询不算）、成功、失败、已报名或已取消状态，失败结论会写清到达的停止条件（达到最大提交次数/重试时长到了/报名已截止）；可以取消尚未提交的单场，也可以停止整个计划，停止后能一键把失败/取消的场次重新选上。
- **看进度**：日志保留脚本原话，收起时只占一行、点「展开」看全部，还能复制和打开数据目录。「距开放」和计划倒计时每秒更新，最后 10 秒变红。想看着浏览器点按钮就勾「显示浏览器窗口」。路线图上的「本次启动 / 活动页已打开 / 盯按钮」是**实际事件时间**：还没发生的节点只显示「待启动 / 待打开 / 待发生」，不用计划时间冒充；已开放场次页面加载再慢，你设置的重试窗口也从启动那一刻起算，不会被慢页面往后推。
- **看结果**：成功会提示“报名成功：活动名”并建议去活动页确认一眼；失败会写清名额、页面、登录态或网络原因，单场失败不会覆盖其他场次。
- **先看条款再开始**：第一次打开会先弹「使用条款与隐私告知」——在阅读区查看五项要点，标题栏保留「查看完整条款」按钮，可在同一窗口切换读十一节全文；点「我已阅读并同意」后才开始校验登录、刷新活动列表（同意记录只存在这台电脑的设置里）。点「暂不使用」不会退出：登录、活动列表和报名计划保持停用，「帮助」入口还在，同一版本不会反复弹，随时可从「帮助 → 查看条款」回来同意；如果某次没能确认条款版本状态，顶部横幅会给出「查看条款」入口重新核对。已同意后再从帮助打开是只读查看，不会二次保存。
- **随时看帮助**：第一次打开先完成条款选择（见上），同意后会**自动走一遍六步界面引导**（登录账号 → 查看活动 → 筛选活动 → 选择活动 → 设置并开始 → 查看结果，每步高亮对应区域）；随时可「跳过引导」或按 Esc 结束。以后从右上角「帮助 → 重看引导」重播。「帮助」同时给三步快速说明（登录账号 / 设置报名计划 / 查看报名结果）——**勾选活动不会自己开始，要点「开始报名计划」**；版本、手动检查更新、前往下载页、打开数据目录和「查看条款」也在同一弹窗。
- **组件坏了会明说**：程序组件（内置的 grab-worker）缺失或无法读取时，登录和开始会禁用，并给出一条明确提示——「程序组件缺失，请重新下载完整版本」——点横幅上的「重新检查」可复查恢复；不会再把组件问题冒充成网络断开、登录失效或「没有活动」，列表加载失败也必定给结论，不会一直转骨架。
- **刷新**：F5、Ctrl+F 跳搜索框、Esc 收起结论或清空选择；右上角「刷新」一次完成检查登录态和拉活动列表。

界面会记住筛选条件、显示浏览器窗口选项和日志展开状态（保存在登录态同一目录的 `ui.json`），下次打开不用重新点一遍。点界面右上角「数据目录」按钮（展开运行记录后也有）可以直接打开实际目录；想恢复默认就删掉里面的 `ui.json`。

界面调用 `app.py` 暴露的本机接口，计划协调由 `signup_plan.py` 负责，单场报名仍复用 `grab.py`；日志可以用来对照命令行排查。
界面启动后用的是 `pythonw`，不会再额外留一个黑窗口。

窗口用 **pywebview + WebView2** 渲染（`local/app.py` 起窗，`local/ui/` 下是 HTML/CSS/JS）。
WebView2 运行时 Windows 10/11 一般自带；万一窗口是空白，装一次
[WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) 即可。
依赖里因此多了 `pywebview`，`install.bat` 会一起装上，已经装过老版本的同学再跑一次 `install.bat`。

想调界面样式又不想登录？在 `local` 目录执行 `python app.py --demo`，会用几条假活动把界面跑起来。

## 四、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 双击 bat 窗口一闪就没 | 先双击 `install.bat` 跑一遍，它会说明缺什么；也可以 Win+R 输 `cmd`，把 bat 拖进去回车，看完整报错 |
| `[X] 没有找到 Python` | 装 Python 时没勾 "Add python.exe to PATH"，重装或手动把 Python 加进 PATH |
| `[X] 依赖没装好（缺 playwright）` | 双击 `install.bat` |
| 界面报 `ModuleNotFoundError: No module named 'PIL'` | 老版本装过依赖，重跑一次 `install.bat` 补上 pillow |
| `[X] 登录态已失效` | 学校接口返回 4001（约 17 小时后），重做第 1 步；网络不通只会显示「登录待确认」，不会要求重登 |
| 界面打不开 / 双击后没反应 | 先用 `install.bat` 自检；或在 local 目录运行 `python app.py` 看报错；窗口空白多半是缺 WebView2 运行时 |
| `[i] 没有可报名（未报名且已公布报名时间）的活动` | 活动还没公布报名时间，或你都已经报了 |
| `[X] 报名未成功：code:xxx ...` | 服务端拒绝：名额已满 / 未到开放时间 / 活动已结束。可以手动打开活动页再试 |
| `[X] 打不开登录页` | 校园网/代理问题，或需要连学校 VPN |
| `[X] 没找到可用的浏览器` | 电脑上既没有 Chrome 也没有 Edge（很少见）。装一个，或运行 `python -m playwright install chromium` |
| 绿色版双击 `启动.bat` 没反应 | 解压不完整（Windows 有时会拦压缩包里的 exe）：重新解压，或右键压缩包 → 属性 → 勾「解除锁定」 |
| 绿色版弹「智能应用控制已阻止可能不安全的文件」 | 下载来的文件带"来自 Internet"标记，被系统拦了。解压前右键 zip → 属性 → 勾「解除锁定」再解压；已解压则在文件夹里跑 `Get-ChildItem -Recurse \| Unblock-File`。详见同目录 `启动不了点我.txt` |
| 单独下载的 EXE 报「本机脚本没能启动」/登录没反应 | **历史旧包口径**：v1.1.0 前的 EXE 必须和 `grab-worker.exe` 同目录，缺了就报错。新版 EXE 已内置组件独立可用；若新版仍提示「程序组件缺失，请重新下载完整版本」，说明下载不完整或文件被系统锁定（右键 → 属性 → 解除锁定），处理后点「重新检查」 |
| 运行了但没窗口 | 正常，默认后台执行；想看着它点加 `--headed` |
| 顶栏时间显示「待校准」，开始按钮写「北京时间未校准」 | 工具没能连上授时服务（断网/防火墙拦 UDP）。恢复网络后点时间详情里的「重新校准时间」；工具不改电脑时间，也不会因校时失败清登录 |
| 报名成功了我其实不想去 | 尽快在活动页取消，别占名额 |

## 五、文件说明

```
local/
├─ install.bat              首次使用双击一次：装依赖 + 内核 + 自检
├─ _py.bat                  四个 bat 共用的 Python 探测（缺环境时提示去装）
├─ grab.py                  主脚本（登录 / 查活动 / 到点自动报名 / 自检）
├─ app.py                   图形界面外壳和多活动计划 API
├─ signup_plan.py           报名批次、活动时段冲突和任务状态协调器
├─ ui/                      界面本体：index.html / styles.css / app.js
├─ gui.py                   旧版 tkinter 界面（已停用，保留作对照）
├─ gui-preview.png          界面预览图（README 用）
├─ requirements.txt         依赖清单：playwright + pillow + pywebview
├─ config.example.json      可选：飞书群机器人 webhook（复制成 config.json 再填）
├─ 1-登录.bat               双击：手动登录一次
├─ 2-抢活动.bat             双击：交互式选择并到点自动报名（历史命名）
├─ 3-检查登录和活动.bat     双击：看登录态 + 列活动
├─ 4-图形界面.bat           双击：打开图形界面
├─ 启动不了点我.txt         绿色版打不开时的排查步骤（含智能应用控制拦截怎么解除）
├─ 遇到问题先看我.txt       安装版/解压版排障：装在哪、数据在哪、怎么卸载、日志在哪
├─ make_portable.py         打绿色版用（开发者跑一次，产物在 ../dist/）
├─ build_exe.py             用 PyInstaller 构建 onedir/onefile EXE（不自动安装工具）
├─ build_installer.py       用 Inno Setup 把 dist 里的 EXE 打成安装版（产物在 ../dist/installer/）
├─ installer/
│  └─ ChineseSimplified.isl 安装向导的简体中文文案（UTF-8 带 BOM，官方 Inno 不带）
└─ data/                    运行后自动生成（EXE 版对应 %LOCALAPPDATA%\TianSoftActivityPreRegistration\data）
   ├─ session.json          你的 token 等登录信息（⚠️ 别外传、别提交到 git）
   ├─ storage_state.json    浏览器登录态（cookie + localStorage）
   ├─ ui.json               界面偏好（筛选词 / 勾选 / 日志展开）
   └─ grab.log              运行日志（不含密码/验证码/token/姓名/学号）
```

> 双击 bat / python 运行时上表 `data/` 就是 `local/data/`；EXE 版统一在 `%LOCALAPPDATA%\TianSoftActivityPreRegistration\data`，从界面「数据目录」按钮打开的是实际所在目录。

## 六、和服务器版有什么不同

| | 宿舍电脑版（本目录） | 服务器版（tjise-activity-watch） |
|---|---|---|
| 登录 | 手动输入账号密码 + 验证码 | Tesseract OCR 自动识别验证码，无人值守 |
| 运行方式 | 你在电脑前，双击或命令行 | 常驻服务器，cron 定时 |
| 依赖 | Python + playwright | Python + playwright + tesseract + Node |
| 适合 | 临时报一两次、舍友也能用 | 长期无人值守推送 + 自动报名 |

## 独立北京时间（决策 012，2026-10-26 返修轮更新）

无需校准系统时间：`business_clock.py` 用公共 NTP（阿里云×2 + Cloudflare）做有界校时，业务时刻 = 锚点 + 经过时长（Win32 GetTickCount64）。CLI `grab.py` 自带一次有界同步；图形界面/打包 worker 复用主程序快照（TJISE_CLOCK_SNAPSHOT/OWNER）。

图形界面只有一个时间入口：顶栏「北京时间 + 时分秒 + 状态图形」，正常安静显示；未校准显示「待校准」，点开「时间详情」可看最近校准、估计误差、使用记录和时间来源，并提供「重新校准时间」（失败态「重试校准」）。时钟不可用时开始按钮禁用（「北京时间未校准」），登录校验不受影响；工具不会修改电脑时间。示例输出与真实授时是两回事：`--demo` 的顶栏时间标注「演示时间」。失败重试与门禁见 design/decisions/012；登录剩余估算未知时不要求重登；原有 CLI/EXE/ZIP 用法不变。

# server/scripts/dev/

一次性排查脚本，**不参与线上链路**（cron、systemd、bot 都不会调用它们）。

| 脚本 | 用途 | 何时用 |
|------|------|--------|
| `explore.py` | 重新探索接口与页面结构 | 学校站点改版、字段对不上 |
| `probe_login.py` | 单独验证登录链路 / 登录态是否可用 | 排登录问题，不想跑完整 fetch |
| `push_card.py` | 手工往指定会话推一张卡片 | 调卡片版式 |

约定：

- 这些脚本可能连真实接口，跑之前确认不会把测试数据写进线上状态；
- 改完仍要过 `py_compile` 与乱码检测；
- 如果某个脚本变成长期需要的能力，应该提升到 `server/scripts/` 并补测试，而不是一直留在 dev 里。

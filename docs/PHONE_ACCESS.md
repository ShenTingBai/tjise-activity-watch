# 手机受限访问（PHONE_ACCESS）

在电脑旁的这台工具上**显式开启**后，可以用手机浏览器查看本机活动缓存、
做 8 项操作、必要时重登。默认**完全关闭**，不监听任何端口。

> 边界先说清楚：这是个人受限适配层，不是远程服务器。它只服务
> **本机回环**或**你自己的 Tailscale 专属地址**，不改防火墙、不开公网隧道。
> **本轮没有在真实手机 / Tailscale / 学校链路上验收过**，下面写的是设计与
> 离线测试已覆盖的行为。

---

## 一、怎么开启

1. 在电脑上的工具窗口里找到「手机访问」面板。
2. 点「开启手机访问」。面板会显示**监听地址**和一个 **6 位一次性配对码**。
   - 配对码只在这里显示，**不进 URL、不落日志**，5 分钟内有效、一码一次。
3. 在手机浏览器打开那个地址，输入配对码，点「配对」。
4. 用完在电脑上点「关闭手机访问」，或直接关掉工具——**关闭会撤销全部会话**。

只有两类地址允许绑定：

| 允许 | 例子 | 说明 |
|---|---|---|
| 本机回环 | `127.0.0.1`、`localhost` | 只有这台电脑自己能访问 |
| Tailscale 专属地址 | `100.64.x.x` / `100.x.x.x` | 你自己 tailnet 内的设备；先装好并登录 Tailscale（本工具**不帮你装、不帮你启**） |

**拒绝**：`0.0.0.0`、公网 IP、普通局域网（`192.168.*` / `10.*` / `172.16.*`）、IPv6。
端口固定 **8765**。

### 走 Tailscale 时

- 先在电脑与手机上都装好 Tailscale 并登录同一账号（这一步在本工具之外完成）。
- 开启手机访问时把绑定地址填成电脑的 `100.64.x.x`（面板默认给 `127.0.0.1`）。
- 手机浏览器访问 `http://100.64.x.x:8765`，用同一个配对码配对。
- 传输安全**依赖 Tailscale 的加密**：这是 HTTP 明文服务，cookie 不谎加
  `Secure`（那会让 HTTP 直接不可用），离开 tailnet 就不要用。

## 二、8 项操作

配对成功后手机上能做：

1. **读取完整缓存**：活动、登录结论、计划快照、北京时间、条款状态（都是本机缓存）。
2. **筛选**：名称/关键词、报名状态（全部/可报名/已报名）、开放时间（不限/今天/7 天内）。
3. **勾选可报名活动**：时间未知或已截止的场次不可执行；资格与冲突仍由电脑端缓存最终裁决。
4. **三种重试模式和次数**：2 分钟 / 10 分钟 / 30 分钟 / 1 小时 / 自动延长（最多 25 分钟）/ 直到报名截止；次数 0 = 不限。
5. **开始 / 停止 / 取消单场**：停止与取消都要**二次确认**；未确认的开始只用同一个请求 ID 只读对账，不鼓励重复点击。
6. **权威进度**：倒计时优先用后端已接纳的截止（含合法扩窗后的权威值）。
7. **日志**：最近的运行记录（截断、脱敏）。
8. **验证码重登**：见下节。

手机页面会**单飞轮询**（前台 1 秒 / 后台 5 秒，断线指数退避最多 15 秒）；
状态超过 5 秒没更新就显示「离线/未知」并禁用「开始」和「重登提交」，
「停止」仍然可点。切回前台会重新拉全量快照，**不会自动重发写操作**。

---

## 三、手机重登（人工验证码）

登录失效时可以**在手机上重登**，但要先在电脑上做一步准备：

1. **电脑上**：在「准备手机重登」里填账号和密码，点「准备」。
   - 账号密码**只保存在当前工具进程的内存里**：不写偏好、不写文件、
     不进命令行、不进日志；密码输入框会立刻清空。
   - **关掉工具就没了**，下次要重新准备（这是刻意的隐私取舍）。
2. **手机上**：点「在手机上重登」，等验证码图片出来（只接受 `data:image/png;base64`）。
3. 抄下 4 位字母数字验证码，点「提交验证码」。
   - 每个验证码**只能用一次**、60 秒内有效；到期可以显式「换一张图」。
   - **最多 3 次**人工提交，工具不会自动乱猜验证码。
4. 成功后工具会自动刷新登录结论与活动列表；**不会自动重新开始计划**——
   你要重新选场次、再点开始。

三种情况会明确拦下：

- **还没准备**：手机上提示「请先在电脑上准备账号密码」。
- **报名计划还在跑**：提示先**停止计划并等终态**，再重登。工具**绝不会**
  自动重发结果未知的任务、也不会自动重建计划。
- **演示模式**：不联网，不启动重登。

**桌面原本的手动登录照旧可用**（在真实浏览器里自己输账号密码和图形
验证码），那条路径的「密码不落盘」承诺不变。

## 四、安全边界（值得知道的实现取舍）

- **配对**：6 位密码学随机码，5 分钟有效、一码一次；单 IP 连错 3 次锁 60 秒，
  换 IP 也逃不过全局限速。
- **会话**：256 位随机 cookie，`HttpOnly` + `SameSite=Strict` + `Path=/`，
  8 小时、只存内存、停服务即撤销；校验不刷新寿命。
- **写请求**：必须带配对时发的 CSRF 头，`Origin` 必须逐字等于服务自己的
  地址，拒绝跨源 / 无 Origin / 伪造 Host。
- **动作白名单**：手机只能调 8 项操作对应的入口；`shutdown`、`open_data`、
  `update`、改条款、改路径这些**永远不可达**，也不会反射任意内部方法。
- **静态页**：只认固定的 4 个文件（入口/样式/脚本），杜绝目录遍历。
- **请求体**：≤ 64 KiB，拒绝非法 JSON / 坏 UTF-8 / NaN；异常不回堆栈。
- **事件**：手机只拿到脱敏、截断后的事件；缓冲最多 400 条，断线太久就整体
  重置快照，不漏中间状态装作连续。

## 五、明确没做的

- **没有在真实手机 / 真实 Tailscale / 学校链路上验收**（本轮只做离线技术验证）。
- 不代他人报名、不批量提交、不做任何绕过风控的操作。
- 列表空态、服务器版、打包发布、C01 直发边界**不在本次范围**。
- 电脑必须**保持唤醒**：手机只是遥控器，真正执行报名的还是电脑上的工具。

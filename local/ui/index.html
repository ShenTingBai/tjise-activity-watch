6. 个人信息与对外通信

6.1 本机版（Windows 图形界面程序）

  • 处理者：本工具只在你自己的电脑上运行。开发者不接触、不收集、不存储、不传输你的任何个人信息；
  • 信息种类：登录凭据（Cookie/会话令牌）、活动列表缓存、界面偏好与运行记录；
  • 存储位置：仅本机数据目录——冻结程序为 %LOCALAPPDATA%\TianSoftActivityPreRegistration\data，源码与开发形态为程序目录旁的 local/data/；环境变量 TJISE_DATA_DIR 可以覆盖这个位置（对源码态与冻结 EXE 都生效，相对路径按当前工作目录解析），指定后程序读写的、以及界面「打开数据目录」打开的都是覆盖后的目录；
  • 旧数据迁移：冻结程序第一次使用新数据根时，会把旧版 EXE 旁边的 data/ 里的登录态与偏好复制到统一数据目录，只补缺失、不覆盖目标已有文件，源文件保留在原处不删除；迁移完成后旧 EXE 旁那份副本依然存在，是否删除由你自行确认；
  • 保存与删除：保存到你删除该目录为止。删除某个目录只删除该目录里的内容。卸载向导里「是否一并删除登录数据」的确认只针对默认数据目录 %LOCALAPPDATA%\TianSoftActivityPreRegistration：默认停在「否」，静默卸载一律保留；TJISE_DATA_DIR 指定的目录与旧 EXE 旁的迁移源副本都不在卸载的删除范围内，需要你自行确认路径后逐一清理。本机是否还存在其他副本（备份、同步盘、系统还原点）不在删除动作的控制范围内，需要你自行确认。程序不设云端备份，也不向开发者上传任何内容；
  • 对外通信（实际会发生的三类）：
    1. 学校系统：登录、登录态校验、活动列表、报名提交与计划执行——其中登录态校验与活动列表在你同意条款后会按界面操作与周期刷新发生，不限于你手动点击的那一次；
    2. 网络授时（NTP / 公共 HTTP 时间源）：程序启动与运行期间会为「独立北京时间」校时，这是时间服务，不携带账号或活动信息；
    3. GitHub 发布页：只有你点「检查更新」或「前往下载页」时才会访问，用于比较版本号，不自动下载、不自动安装；
  • 除以上三类，程序不向其他第三方发送数据；它不内置任何开发者侧的遥测或统计；
  • 你的权利：查阅与备份（打开数据目录即可）、更正（界面设置）、删除（删除数据目录）、撤回同意（停止使用并删除数据；未同意条款时学校动作本就保持停用）。

6.2 服务器版（自行部署者适用）

  • 部署服务器版的你才是个人信息处理者：服务器上的会话文件、活动缓存与推送记录都在你的服务器上，由你负责保管、权限设置与删除；
  • 服务器只使用部署者本人的学校会话查询活动字段；群成员不需要、也不要向机器人提供学校账号或密码（这一点请在群内自行说明）；
  • 群机器人只读：向群里推送公开活动信息、回答查询；不替群成员执行任何报名动作；
  • 私聊机器人仅服务于部署者本人（owner）的预报名与结果通知；
  • 飞书侧接收与保存的数据：飞书开放平台会把消息与卡片交互事件发到你的服务，其中包含发送者的 open_id、会话 chat_id、消息内容与卡片交互字段；这些数据的保存期限、删除与权限由你决定并负责；

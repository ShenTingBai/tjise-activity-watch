# 校园活动「到点自动报名」—— 本机版

> 这个文件同时是 GitHub **`local` 分支**的首页。三条分支的分工：
> `main` 源码总仓（两版并存）、`local` 本机版快照（就这一份，根目录双击即用）、`server` 服务器版快照。
>
> 不想装 Python：下 [Releases](https://github.com/ShenTingBai/tjise-activity-watch/releases) 里
> **`天软活动预报名工具-vX.Y.Z-win-x64.zip`** 完整便携包（约 60 MB），解压双击主 EXE 就能用
> （内置依赖，使用电脑上的 Chrome 或 Edge）。绿色版 `tjise-grab-portable-*.zip` 是另一种打包形态，
> 同样可用。

只用自己电脑，不需要服务器。服务器版（定时推送、飞书机器人、无人值守重登）在仓库的 `server/` 目录，也可以直接看分支 [`server`](https://github.com/ShenTingBai/tjise-activity-watch/tree/server)。

一个**不需要服务器**的小工具：在你自己的 Windows 电脑上登录一次，之后把多场活动加入计划，脚本会在各自开放时刻自动点「立即报名 → 确定」。

适用于「天软智慧校园」活动中心的第二课堂活动（站点 `https://xg.tjise.edu.cn/stu/`），**只对天津市大学软件学院（天软）专升本学生有效**。

---

## 一、先说清楚边界

这个工具只在你自己的账号上运行报名计划：每场活动在报名开放的那一刻提交，计划统一协调不同开放批次。

- ✅ 只操作你本人的账号（登录态来自你自己手动登录）
- ✅ 只点「立即报名」和弹窗里的「确定」，不碰别的接口
- ✅ 密码不落盘：登录在真实浏览器窗口里由你手动输入（含图形验证码），脚本只保存 cookie/localStorage
- ❌ 不代他人报名、不批量抢、不做任何绕过风控的操作
- ❌ 抢到就等于占用名额，不想去请尽快在活动页取消，别浪费

请遵守学校关于活动的管理规定。抢是抢，诚信是诚信。

## 二、准备（只做一次）

需要 **Windows 10/11** + **Python 3.10 或更高**。

**双击 `install.bat`** 就行，它会自动做完四件事：

| 步骤 | 动作 |
|---|---|
| 1 | 检查 Python 版本（没装会提示去哪下、要勾哪个选项） |
| 2 | 装依赖 `playwright` + `pillow` + `pywebview`（默认源失败自动换清华镜像） |
| 3 | 下载浏览器内核（失败换国内镜像；再失败就用你电脑上的 Chrome） |
| 4 | 自检：能不能拉起浏览器、能不能连上学校站点 |

看到 `[OK] 打开成功` 和「安装完成」就可以往下走了。

> 没有 Python？先装：<https://www.python.org/downloads/>，安装第一屏**务必勾选 "Add python.exe to PATH"**，装完重新双击 `install.bat`。

### 完全不想装 Python：用绿色版

拿到 **`tjise-grab-portable.zip`**（约 59 MB，解压后 150 MB）的话，**不用装 Python、不用跑 install.bat**：

1. 解压到任意目录（路径别带中文和空格，例如 `D:\tjise-grab`）
2. 双击 **`启动.bat`** —— 界面就起来了

里面自带解释器和依赖，只借用你电脑上的浏览器（Chrome 或 Edge 都行，Win10/11 一定带 Edge）。
想用命令行的话，把 `python` 换成 `python\python.exe` 即可，例如 `python\python.exe grab.py list`。

> 绿色版是从 `make_portable.py` 构建出来的：`python make_portable.py`。想自己重新打一份就运行它。
> 打包用的是官方嵌入式 Python + 这台机器上装好的依赖，**不捆绑浏览器内核**，所以比 PyInstaller 小很多、也不容易被杀软误报。

### 两种分发方式

- **绿色版目录/压缩包**（兼容形态）：在 `local` 目录运行 `python make_portable.py`。它会把当前 `app.py`、`grab.py`、`signup_plan.py`、界面资源和依赖放进 `dist/tjise-grab-portable/`，启动器运行当前 WebView 界面。浏览器使用电脑上的 Chrome 或 Edge，登录态写在包旁边的 `data/` 目录。
- **EXE + 完整 ZIP（用户选定形态）**：先在开发机单独安装 PyInstaller，再运行 `python build_exe.py --mode onefile`；或直接 `python tools/release.py --prepare` 一条命令完成「构建 + 按白名单组装资产」。产物是 `天软活动预报名工具-vX.Y.Z-win-x64.exe`（**独立可用单文件**——grab-worker 已作为内置资源打进主程序，拷到空目录双击即可）与 `天软活动预报名工具-vX.Y.Z-win-x64.zip`（完整便携包：独立 EXE + README + 启动说明 + LICENSE 四项），外加一份 manifest 清单（版本、来源 commit、每个文件的 SHA-256）。旧版「主 EXE 必须与 `grab-worker.exe` 同目录」是历史旧包口径，已被 2026-10-25 的独立 EXE 决定取代（见 `design/decisions/010-standalone-exe-and-settings.md`）。构建脚本不会读取 `data/`，也不会把登录态打进包；清理重建时输出目录里的 `data/` 会原样保留（旧版 EXE 旁登录态留给首次启动自动迁移到 `%LOCALAPPDATA%\TianSoftActivityPreRegistration\data`）。`X.Y.Z` 读仓库根 `VERSION`（当前候选 1.1.0，发布前以 VERSION 为准）；资产是本地预览，只有 `tools/release.py --publish` 才会上 GitHub——它要求干净 main、逐项核验资产与来源一致、人工确认，默认不打 tag 不上传。
- **Release 页的 EXE / ZIP 资产**（发布后）：完整 ZIP 是推荐下载；独立 EXE 也可直接用——两者都内置组件，缺组件时会明确提示「程序组件缺失，请重新下载完整版本」，不会再报莫名其妙的 WinError 2。新版资产发布前，Release 页旧资产的形态以各自启动说明为准。

两种方式都需要 Windows WebView2，以及 Chrome 或 Edge 之一。PyInstaller 不负责安装浏览器内核；首次构建前也不会自动安装 PyInstaller。

## 三、三步走

### 第 1 步：登录（每次登录态过期后重做）

双击 **`1-登录.bat`**（或运行 `python grab.py login`）。

会弹出一个 Chrome 窗口，停在学生登录页：

1. 输入学号/账号、密码、图形验证码，点「立即登录」；
2. 登录成功后脚本会自动保存登录态并关闭窗口；
3. 看到 `[OK] 登录成功` 即可。

登录态大概能撑 **17 小时左右**（实测样本，不是保证值）。过期后重新做这一步就行。

> 关闭工具再打开**不需要**重新登录：启动时会先显示「正在检查登录态」，真实校验通过就直接复用（界面提示「已复用本机登录态」）。只有学校接口明确返回失效（4001）才重登；网络异常显示「暂时无法确认登录态」，恢复后点「刷新」再试，已有登录不会被清掉。

### 登录态存在哪、重开还要再登一次吗

- **双击 bat / python 运行**：登录态在 `local/data/`（session.json + storage_state.json），关掉重开、再次运行都直接复用，不用重复登录。
- **EXE 版**：登录态统一存在本机的 `%LOCALAPPDATA%\TianSoftActivityPreRegistration\data`。**同一台电脑上**关闭重开、替换 EXE、甚至重新构建 EXE，打开时都会先用已有登录态真实访问一次学校接口——校验通过就直接用（界面写「已复用本机登录态」），不会重复弹登录窗口；只有学校接口明确返回登录失效（4001）才需要重新登录。网络或学校接口没应答时显示「暂时无法确认登录态」，点「刷新」再试即可，**不会**因此清掉已有登录或逼你重登。
- 这些文件里只有登录凭证（cookie / token），**没有账号密码**；「约剩 17 小时」只是提醒文案，真正的失效以学校接口返回为准。
- **关闭时长与登录估算**：重开工具时点顶栏时钟，能看到「上次关闭时长」和「登录预计还剩」——正常关闭给精确值，上次是崩溃/断电退出的只显示「约」；登录估算按保存时刻的绝对墙钟继续计算（关着的那段时间照算），**只是提醒**：估算到点但学校校验有效时仍显示「登录有效」。这些记录写在 `ui.json`，不碰登录文件。
- 想看或备份这些文件：右上角「帮助 → 打开数据目录」（运行记录展开后也有同名按钮）直接打开所在目录；高级用法可用环境变量 `TJISE_DATA_DIR` 指定别的位置（对开发和 EXE 版都生效）。旧版 EXE 旁边 `data/` 里的登录态会在新版首次启动时自动搬到统一目录，不会丢。
- **看版本与更新**：「帮助」显示当前版本（与 Release 资产同一来源，当前候选 1.1.0，发布前以仓库根 VERSION 为准）。点「检查更新」才查询 GitHub 最新正式版：有新版、当前最新、当前为预览版本或暂无正式发布会分别说明；断网、超时、限流等失败只在更新区提示，可重试。结果附检查时间，重开帮助或刷新界面可恢复本次结果，不会自动再次查询。「查看发布页」用系统浏览器打开固定发布页；打不开会显示地址供复制。检查不会自动下载或安装。
- **重看引导**：「帮助 → 重看引导」重新走一遍六步。计划运行中该按钮禁用并写「计划结束后可重看引导」；帮助、版本检查和数据目录仍可使用。

### 第 2 步：看有哪些活动

双击 **`3-检查登录和活动.bat`**，会打印：

```
  #  报名开始  状态  活动名
  1  2026-10-22 00:59:59  未开放（1 小时 22 分后）  网络安全·数字时代大长城
  2  2026-10-21 10:00:00  开放中  我与学生面对面（天软信息化发展之路）
```

记住你要抢的那个活动的**报名开始时间**（也可以直接用第 3 步的交互选择）。

### 第 3 步：到点自动报名

**推荐：双击 `2-抢活动.bat`**，按提示输入序号并确认，脚本会：

| 时刻 | 动作 |
|---|---|
| 报名开放前约 100 秒 | 打开浏览器加载活动详情页（浏览器冷启动要十几秒，留足余量） |
| 开放前 5 秒 | 开始每 0.3 秒检查页面有没有「立即报名」按钮 |
| 按钮没出现时 | 最多每 2 秒刷新一次页面（避免把学校接口刷爆） |
| 开放瞬间 | 点「立即报名」→ 弹窗点「确定」→ 读服务端返回 |
| 失败 | 每 1.5 秒重试一次，最多重试 120 秒（名额满/未开放都会记下原因） |
| 结束 | 打印成功/失败结论；配了飞书 webhook 的话同时发一张卡片 |

选中的场次**已经开放**时不会傻等原定时刻：脚本立即开始抢，命令行同时打出
「原定开放」（学校原定时间）和「本次执行」（实际起点）两个时间，重试窗口从本次执行起算。

**或者用命令行指定**（适合提前写好、放在后台跑）。两种都行：

```bat
:: 按 list 里的序号（推荐，不用手抄活动 id 和时间）
python grab.py grab --pick 1

:: 按活动名关键词（只匹配到一个才继续）
python grab.py grab --name 网络安全

:: 显式指定（老办法，id 和报名时间都自己填）
python grab.py grab --activity-id 2ae75dd103654543b1a8b97053adf4a6 ^
                    --at "2026-10-22 00:59:59" ^
                    --name "网络安全·数字时代大长城"
```

`--pick` / `--name` 与 `3-检查登录和活动.bat` 打印的序号是同一份顺序；用这两种方式时不再二次确认，直接进入等待抢报名。序号对不上时脚本会告诉你当前有几个，匹配到多个重名活动时会列出来让你改用序号——不会瞎猜一个报名。

常用参数：

| 参数 | 作用 | 默认 |
|---|---|---|
| `--pick N` | 按 list 的序号直接选 | 不用（则交互选择） |
| `--name 关键词` | 按活动名挑选；配合 `--activity-id` 时只作通知名 | 空 |
| `--lead 100` | 提前多少秒打开页面 | 100 |
| `--window 120` | 开放后最多重试多少秒 | 120 |
| `--headed` | 显示浏览器窗口（默认后台静默） | 关 |
| `--dry-run` | 只检查页面和按钮，不提交 | 关 |

**注意：保持电脑不睡眠、不断网。** 笔记本合盖会睡，抢不到不是脚本的锅。

### 不想敲命令行？双击 `4-图形界面.bat`

![界面预览](gui-preview.png)

窗口名是**「天软活动预报名工具」**，一个窗口搞定，打开就会自动检查登录、拉一次活动列表：

- **界面气质**：来自早期「准点」视觉原型的车站候车厅、黑底 LED 计划大屏、白色活动时刻表和底部运行记录——「准点」只是那套设计稿的历史称呼，不是本工具的名字；实际数据和业务由当前 `app.py` 事件驱动。窄窗口下品牌名会缩短为「天软预报名工具」，窗口标题不变。
- **看状态**：顶部显示登录态（快过期变橙）、本机时钟（和学校差 3 秒以上会标出来）、活动总数、可报名数量和下一个开放时间；断网或电脑睡眠过会有顶部横幅提醒。
- **看时刻表**：活动按「正在开放 → 现在 → 今天/明天/以后 → 待公布 → 刚截止 → 已报名」分组；「下一场」有黑底标签，每秒只走倒计时，不重排整表。
- **双模式**：未来开放的场次是「**预报名**」——提前加入计划，工具会在学校原定开放时刻前 **100 秒**自动启动这一场：先打开活动详情页预热，开放前 5 秒进入高频盯按钮，开放后才提交；报名已开放但还没截止的场次是「**立即报名/抢名额**」——选中后马上执行，重试窗口从本次启动起算；报名已截止的场次只能查看，复选框、整行点击和开始按钮都会拒绝它。每行、任务卡和大屏摘要都标着各自模式，混合计划里两种模式可以共存、逐场显示、互不阻塞（一场在重试中，另一场照样按自己的时刻启动）。
- **筛活动**：支持关键词、全部/未报名/已报名、时间、排序，以及“签到：全部/需要/无需”“签退：全部/需要/无需”。接口没有提供要求字段时会显示“待说明”，只在全部筛选里保留——学校字段还没确认时，宁可疑着，不要误判成无需。
- **加入计划**：每行独立勾选，选完大屏给出检查条（登录撑不撑得到开放、时钟准不准、是否 24 小时后才开放）。活动举办时间重叠时保留已有选择并提示冲突；同一报名开放时刻但举办时间不重叠的活动可以一起提交，不同开放批次会提前排队等待。
- **重试策略**：开始计划前可设「重试」（2 分钟/10 分钟/30 分钟/1 小时/直到报名截止）和「最多次数」（0=不限），默认 2 分钟 + 不限——长报名窗口**不会**默认持续运行，只有明确选「直到报名截止」才会挂到截止。活动的**报名截止时间是硬上限**，任何设置都不会越过它；活动没公布截止时间时，「直到报名截止」自动回退 2 分钟，绝不无限跑。设置会记住，下次打开不用重选。图解见 [docs/RETRY_POLICY_GUIDE.md](../docs/RETRY_POLICY_GUIDE.md)。
- **运行计划**：点「开始报名计划」后，任务行显示每场等待、提交中（第 N 次提交 + 最近原因 + 重试截止，只有真正点「立即报名」发起的提交才计数，刷新和查询不算）、成功、失败、已报名或已取消状态，失败结论会写清到达的停止条件（达到最大提交次数/重试时长到了/报名已截止）；可以取消尚未提交的单场，也可以停止整个计划，停止后能一键把失败/取消的场次重新选上。
- **看进度**：日志保留脚本原话，收起时只占一行、点「展开」看全部，还能复制和打开数据目录。「距开放」和计划倒计时每秒更新，最后 10 秒变红。想看着浏览器点按钮就勾「显示浏览器窗口」。路线图上的「本次启动 / 活动页已打开 / 盯按钮」是**实际事件时间**：还没发生的节点只显示「待启动 / 待打开 / 待发生」，不用计划时间冒充；已开放场次页面加载再慢，你设置的重试窗口也从启动那一刻起算，不会被慢页面往后推。
- **看结果**：成功会提示“报名成功：活动名”并建议去活动页确认一眼；失败会写清名额、页面、登录态或网络原因，单场失败不会覆盖其他场次。
- **随时看帮助**：第一次打开会**自动走一遍六步界面引导**（登录状态 → 活动与模式 → 筛选 → 选择与冲突 → 重试与开始 → 运行与结果，每步高亮对应区域）；随时可「跳过引导」或按 Esc 结束。以后从右上角「帮助 → 重看引导」重播。「帮助」同时给三步快速说明（确认登录 / 选活动并开始 / 看进度与结果）——**勾选活动不会自己开始，要点「开始报名计划」**；版本、手动检查更新、查看发布页和打开数据目录也在同一弹窗。
- **组件坏了会明说**：程序组件（内置的 grab-worker）缺失或无法读取时，登录和开始会禁用，并给出一条明确提示——「程序组件缺失，请重新下载完整版本」——点横幅上的「重新检查」可复查恢复；不会再把组件问题冒充成网络断开、登录失效或「没有活动」，列表加载失败也必定给结论，不会一直转骨架。
- **刷新**：F5、Ctrl+F 跳搜索框、Esc 收起结论或清空选择；右上角「刷新」一次完成检查登录态和拉活动列表。

界面会记住筛选条件、显示浏览器窗口选项和日志展开状态（保存在登录态同一目录的 `ui.json`），下次打开不用重新点一遍。点界面右上角「数据目录」按钮（展开运行记录后也有）可以直接打开实际目录；想恢复默认就删掉里面的 `ui.json`。

界面调用 `app.py` 暴露的本机接口，计划协调由 `signup_plan.py` 负责，单场报名仍复用 `grab.py`；日志可以用来对照命令行排查。
界面启动后用的是 `pythonw`，不会再额外留一个黑窗口。

窗口用 **pywebview + WebView2** 渲染（`local/app.py` 起窗，`local/ui/` 下是 HTML/CSS/JS）。
WebView2 运行时 Windows 10/11 一般自带；万一窗口是空白，装一次
[WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) 即可。
依赖里因此多了 `pywebview`，`install.bat` 会一起装上，已经装过老版本的同学再跑一次 `install.bat`。

想调界面样式又不想登录？在 `local` 目录执行 `python app.py --demo`，会用几条假活动把界面跑起来。

## 四、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 双击 bat 窗口一闪就没 | 先双击 `install.bat` 跑一遍，它会说明缺什么；也可以 Win+R 输 `cmd`，把 bat 拖进去回车，看完整报错 |
| `[X] 没有找到 Python` | 装 Python 时没勾 "Add python.exe to PATH"，重装或手动把 Python 加进 PATH |
| `[X] 依赖没装好（缺 playwright）` | 双击 `install.bat` |
| 界面报 `ModuleNotFoundError: No module named 'PIL'` | 老版本装过依赖，重跑一次 `install.bat` 补上 pillow |
| `[X] 登录态已失效` | 学校接口返回 4001（约 17 小时后），重做第 1 步；网络不通只会显示「暂时无法确认登录态」，不会要求重登 |
| 界面打不开 / 双击后没反应 | 先用 `install.bat` 自检；或在 local 目录运行 `python app.py` 看报错；窗口空白多半是缺 WebView2 运行时 |
| `[i] 没有可报名（未报名且已公布报名时间）的活动` | 活动还没公布报名时间，或你都已经报了 |
| `[X] 没抢到：code:xxx ...` | 服务端拒绝：名额已满 / 未到开放时间 / 活动已结束。可以手动打开活动页再试 |
| `[X] 打不开登录页` | 校园网/代理问题，或需要连学校 VPN |
| `[X] 没找到可用的浏览器` | 电脑上既没有 Chrome 也没有 Edge（很少见）。装一个，或运行 `python -m playwright install chromium` |
| 绿色版双击 `启动.bat` 没反应 | 解压不完整（Windows 有时会拦压缩包里的 exe）：重新解压，或右键压缩包 → 属性 → 勾「解除锁定」 |
| 绿色版弹「智能应用控制已阻止可能不安全的文件」 | 下载来的文件带"来自 Internet"标记，被系统拦了。解压前右键 zip → 属性 → 勾「解除锁定」再解压；已解压则在文件夹里跑 `Get-ChildItem -Recurse \| Unblock-File`。详见同目录 `启动不了点我.txt` |
| 单独下载的 EXE 报「本机脚本没能启动」/登录没反应 | **历史旧包口径**：v1.1.0 前的 EXE 必须和 `grab-worker.exe` 同目录，缺了就报错。新版 EXE 已内置组件独立可用；若新版仍提示「程序组件缺失，请重新下载完整版本」，说明下载不完整或文件被系统锁定（右键 → 属性 → 解除锁定），处理后点「重新检查」 |
| 运行了但没窗口 | 正常，默认后台抢；想看着它点加 `--headed` |
| `[!] 本机时钟与服务器相差 xx 秒` | 到「设置 → 时间和语言」里同步一次时间，否则会抢跑或迟到 |
| 抢成功了但我其实不想去 | 尽快在活动页取消，别占名额 |

## 五、文件说明

```
local/
├─ install.bat              首次使用双击一次：装依赖 + 内核 + 自检
├─ _py.bat                  四个 bat 共用的 Python 探测（缺环境时提示去装）
├─ grab.py                  主脚本（登录 / 查活动 / 抢报名 / 自检）
├─ app.py                   图形界面外壳和多活动计划 API
├─ signup_plan.py           报名批次、活动时段冲突和任务状态协调器
├─ ui/                      界面本体：index.html / styles.css / app.js
├─ gui.py                   旧版 tkinter 界面（已停用，保留作对照）
├─ gui-preview.png          界面预览图（README 用）
├─ requirements.txt         依赖清单：playwright + pillow + pywebview
├─ config.example.json      可选：飞书群机器人 webhook（复制成 config.json 再填）
├─ 1-登录.bat               双击：手动登录一次
├─ 2-抢活动.bat             双击：交互式选择并到点抢
├─ 3-检查登录和活动.bat     双击：看登录态 + 列活动
├─ 4-图形界面.bat           双击：打开图形界面
├─ 启动不了点我.txt         打不开时的排查步骤（含智能应用控制拦截怎么解除）
├─ make_portable.py         打绿色版用（开发者跑一次，产物在 ../dist/）
├─ build_exe.py             用 PyInstaller 构建 onedir/onefile EXE（不自动安装工具）
└─ data/                    运行后自动生成（EXE 版对应 %LOCALAPPDATA%\TianSoftActivityPreRegistration\data）
   ├─ session.json          你的 token 等登录信息（⚠️ 别外传、别提交到 git）
   ├─ storage_state.json    浏览器登录态（cookie + localStorage）
   ├─ ui.json               界面偏好（筛选词 / 勾选 / 日志展开）
   └─ grab.log              运行日志（不含密码/验证码/token/姓名/学号）
```

> 双击 bat / python 运行时上表 `data/` 就是 `local/data/`；EXE 版统一在 `%LOCALAPPDATA%\TianSoftActivityPreRegistration\data`，从界面「数据目录」按钮打开的是实际所在目录。

## 六、和服务器版有什么不同

| | 宿舍电脑版（本目录） | 服务器版（tjise-activity-watch） |
|---|---|---|
| 登录 | 手动输入账号密码 + 验证码 | Tesseract OCR 自动识别验证码，无人值守 |
| 运行方式 | 你在电脑前，双击或命令行 | 常驻服务器，cron 定时 |
| 依赖 | Python + playwright | Python + playwright + tesseract + Node |
| 适合 | 临时抢一两次、舍友也能用 | 长期无人值守推送 + 抢报名 |

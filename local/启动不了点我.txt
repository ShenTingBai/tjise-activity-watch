==========================================================
  启动不了？先看这里
==========================================================

一、双击「启动.bat」或「4-图形界面.bat」，弹窗说：
   「智能应用控制已阻止可能不安全的文件」

   原因：zip 是从网上下载的，Windows 会给解压出来的程序打上
   "来自 Internet" 的标记；智能应用控制不放行来源不明的可执行文件。
   这不是程序有问题，也不是中毒。

   解决（推荐，不用关任何安全设置）：

     情况 1：zip 还没解压
       右键 zip → 属性 → 勾选底部的"解除锁定" → 确定 → 再解压。

     情况 2：已经解压了
       打开解压出来的文件夹 → 点地址栏 → 输入 powershell 回车 →
       粘贴下面这行执行：
         Get-ChildItem -Recurse | Unblock-File
       然后重新双击「启动.bat」。

   如果还是被拦：
     设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制
     → 智能应用控制 → 设置 → 关闭
     注意：关掉之后不能重新打开，只能重装系统才能恢复，非必要别关。

   更稳的做法是别用绿色版，走源码版：
     装 Python 3.10+，然后
       pip install playwright
       playwright install chromium
     再双击「4-图形界面.bat」。

----------------------------------------------------------

二、双击后一闪而过，什么都没出现

   说明启动脚本自己报错了。在文件夹地址栏输入 cmd 回车，执行：
     _py.bat gui

   看最后的报错。常见原因：
     - 提示"未检测到 Python"  → 先双击「install.bat」装环境
     - 提示没有 playwright    → 再跑一次「install.bat」
     - 其它报错               → 截图发我

----------------------------------------------------------

三、界面能开，但表格是空的

   1. 点「检查登录」，看右上角状态：
      显示"登录态失效" → 点「登录 / 重新登录」
   2. 显示"登录态：有效"但列表仍为空 → 点「刷新活动」再试一次

----------------------------------------------------------

四、登录了还是抢不到

   - 电脑进入了睡眠 / 断网 → 抢之前把电源计划改成"不睡眠"
   - 界面被关掉了           → 抢的过程要一直开着（可以最小化）

先确认你手上是哪种形态，两者启动方式不同，别混用步骤：

  · 安装版：双击安装程序装过一次，开始菜单里能搜到
            「天软活动预报名工具」。下面按这个写。
  · 解压版：直接解压出来的文件夹，双击里面的
            tjise-activity-watch.exe 打开，删掉文件夹就等于卸载。
  · 绿色版：文件夹里有一堆 .bat 的，请改看包里的
            「启动不了点我.txt」。

版本号看程序里右上角「帮助」显示的那一串，排障时可以一并说明。

一、程序装在哪？以后怎么打开

  平时不用记路径：在开始菜单搜「天软活动预报名工具」就能打开。
  安装时勾了「在桌面上创建快捷方式」的话，桌面上也有。

  安装版默认装在（不需要管理员权限）：
    %LOCALAPPDATA%\Programs\TjiseActivityWatch
  安装时选了「为所有用户安装」则在：
    C:\Program Files\TjiseActivityWatch
  （解压版：就在你解压出来的那个文件夹里，双击 exe。）

二、双击没反应，或弹窗说「智能应用控制已阻止」

  原因：程序是从网上下载的，Windows 会给安装包打上
  "来自 Internet" 的标记；智能应用控制不放行来源不明的可执行文件。
  这不是程序有问题，也不是中毒。

  解决（不用关任何安全设置）：

    情况 1：安装包还没运行
      右键安装包 → 属性 → 勾选底部的"解除锁定" → 确定 → 再双击安装。

    情况 2：已经装完，快捷方式打不开
      打开安装目录 → 点地址栏 → 输入 powershell 回车 → 粘贴执行：
        Get-ChildItem -Recurse | Unblock-File
      然后再打开程序。

    如果还是被拦：
      设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制
      → 智能应用控制 → 设置 → 关闭
      注意：关掉之后不能重新打开，只能重装系统才能恢复，非必要别关。

    杀毒软件（360、火绒等）提示"风险"时属于对未签名程序的通用提醒，
    选择"信任/允许运行"即可；不放心可以只用官方下载渠道的安装包。

三、窗口能打开，但里面一片空白 / 一直转圈

  原因：Windows 缺少 WebView2 运行时（界面靠它渲染）。

  解决：
    1. 打开 https://developer.microsoft.com/microsoft-edge/webview2/
       下载「常青版独立安装程序」装上，重启程序；
    2. Windows 10/11 一般自带，装过 Edge 基本都有；
    3. 装完还空白，把窗口大小拖一下再看。

----------------------------------------------------------

四、表格是空的 / 提示登录状态失效

  1. 点「刷新」，看右上角状态：
       显示「登录已失效」 → 点「登录 / 重新登录」
  2. 显示「已登录」但列表仍为空 → 再点一次「刷新」
  3. 换台电脑、换浏览器登录过之后，旧登录会失效，重登一次即可。
  4. 第一次使用本来就要先登录一次，不然列表就是空的。

五、数据存在哪？怎么备份、怎么彻底删掉

  位置（跟装在哪无关，装到 C:\Program Files 也不会变）：
    %LOCALAPPDATA%\TianSoftActivityPreRegistration\data

  程序里也能一键打开：右上角「帮助」→「打开数据目录」，
  打开后程序会把完整路径写在帮助里，可以直接复制。

  这个文件夹里有什么：
    session.json         登录凭证（属于个人登录信息，别外传）
    storage_state.json   浏览器登录信息（cookie 等）
    ui.json              界面偏好（筛选词、勾选、日志展开状态）
    grab.log             运行记录（不含密码、验证码、token、姓名、学号）

  备份：把整个文件夹拷走即可。恢复：拷回同一路径。
  彻底删除：删掉上面这个文件夹——只删这一处的内容，下次使用需要重新登录。
    注意：上面这个是默认位置。如果你设过环境变量 TJISE_DATA_DIR，程序实际读写的
    是那个自定义目录，删默认文件夹清不掉它；旧版 EXE 旁 data/ 迁移过来的原文件
    也还留在原处。想全部清干净，要把这几处路径逐一确认后分别删除——删一个目录
    只删掉那个目录里的东西，不等于所有副本都没了。

六、怎么卸载

  安装版：
    设置 → 应用 → 已安装的应用 → 搜「天软活动预报名工具」→ 卸载
    （也可以从开始菜单里点「卸载 天软活动预报名工具」）

    卸载只删程序本身，默认保留上面那份登录数据，重新安装后可以直接用。
    想连登录数据一起清掉，卸载向导里有单独一栏会问：默认停在「否」，
    要你自己点了「是」才会删。
    静默卸载（/VERYSILENT 这类不带界面的方式）一律保留数据——
    没有人回答过这个问题，就不能替你决定删掉。

    说明：安装包本身（安装版）目前是仓库里的构建产物，正式发布后才会在
    GitHub Releases 上提供下载；发布前自己构建出来的安装包只用于本机试用。

  解压版：
    直接删掉整个文件夹即可。要连登录数据一起清，再删掉第五步里那个
    %LOCALAPPDATA%\TianSoftActivityPreRegistration 文件夹。
    这只覆盖默认位置：设过 TJISE_DATA_DIR、或旧版 EXE 旁还留着迁移源副本的，
    要按第五步把每处路径逐一确认后分别删除。

七、登录了但报名没有成功

  - 电脑进入了睡眠 / 断网 → 开始计划前把电源计划改成"不睡眠"
  - 界面被关掉了           → 计划运行期间要一直开着（可以最小化）
  - 提示「名额已满」       → 本场确实放完了，看别的场次
  - 报名结果以学校活动页为准，工具显示「待核对」时去活动页确认一眼
